Salary Reality Check

An interactive, scroll-driven story that compares what a salary actually buys in different cities after taxes, rent, and cost-of-living—not just nominal dollars.

Live demo GitHub Back to portfolio

Idea

Job posts advertise the same number everywhere, but purchasing power is local. This project makes that concrete across fifty U.S. cities using public wage, rent, and tax logic so users can reason about tradeoffs without spreadsheets.

Implementation

  • React 18 and Vite for a fast, component-driven UI.
  • D3.js for bespoke charts and scrollytelling transitions tied to narrative steps.
  • Tailwind CSS for consistent spacing and responsive layout.
  • Python tooling in the repo for data prep (BLS wages, Zillow rent index, tax calculations).
  • Shareable state via URL parameters so a specific city comparison can be linked.

Takeaway

Good data journalism is accurate and inviting: the math has to hold up, and the interface has to reward curiosity without overwhelming readers.
