Data Analysis: Human Impact

A web front end for exploring human-impact datasets—climate pressures, resource use, and population dynamics—with a Python data pipeline feeding interactive D3-driven views.

Live demo GitHub Back to portfolio

Goals

Global datasets are often published in forms that discourage exploration. This project splits responsibilities: Python cleans and shapes the data; the browser focuses on interaction and clarity.

Stack & flow

  • Python pipeline to validate joins, derive metrics, and emit web-friendly artifacts.
  • Vanilla JavaScript modules organizing chart lifecycles and user events.
  • D3.js for scales, layouts, and updates—not just static one-off graphics.
  • Hosted on GitHub Pages for simple, versioned deployment.

Learning

Splitting “data correctness” from “presentation logic” keeps both sides testable and makes it easier to swap datasets without rewriting the entire UI.
