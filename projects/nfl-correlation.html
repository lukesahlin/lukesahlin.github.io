NFL Offense vs. Defense Correlation

Statistical exploration of how team offensive and defensive performance metrics move together, backed by Python processing and a browser-based chart layer for league-wide comparison.

GitHub Back to portfolio

Approach

Sports stats are noisy: strength of schedule, injuries, and sample size all matter. This project focuses on transparent correlation structure—what pairs of team metrics co-vary and how that shows up when you scan the whole league.

Components

  • Python ingestion and cleaning of team-level offensive and defensive statistics.
  • Correlation summaries to guide which relationships are worth visual emphasis.
  • Interactive HTML/JavaScript visualization to filter and compare teams without rerunning notebooks.

Outcome

A compact example of the analytics pattern I like: reproducible backend, lightweight frontend, and a narrative grounded in the actual distributions behind the averages.
