Options Flow Analytics Dashboard

A financial analytics stack that ingests market-by-order options and futures data, surfaces institutional-style signals, and pairs a fast analytic backend with an interactive React frontend.

Live dashboard GitHub Back to portfolio

Problem

Raw options and ES futures MBO feeds are enormous. The interesting story is rarely a single print—it’s how liquidity pulls and stacks around strikes and expiries, and how that relates to greeks and positioning.

What I built

  • Ingestion and analysis pipelines using Polars and PyArrow for columnar performance.
  • DuckDB for ad-hoc SQL over large extracts without standing up a heavy warehouse.
  • FastAPI services to serve curated datasets and queries to the UI.
  • React 18 frontend with Plotly.js— including 3D greeks surfaces for intuitive exploration.
  • Detection heuristics for pulling/stacking-style behavior to highlight unusual flow.
  • Static deployment on GitHub Pages with CI/CD for repeatable builds.

Why it matters

This project brings together systems thinking (data volume, API contracts) and visualization: analysts need both trustworthy aggregates and a UI that does not get in the way.
