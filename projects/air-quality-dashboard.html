Air Quality Dashboard — Spokane

A production-oriented platform for environmental stakeholders to manage air-quality sensors, sites, and users, with automated anomaly detection and secure multi-role access.

GitHub Back to portfolio

Context

This project is my senior capstone (CPSC 491/492) in partnership with Gonzaga University’s Institute for Climate, Water, and the Environment. The goal is to give Spokane and partner organizations a trustworthy place to monitor sensor health and air-quality readings—not just static charts, but operations tooling for the people maintaining the network.

What I built

  • Full-stack admin experience for sensors, deployment sites, and user accounts.
  • Real-time and historical data pathways with variance-based logic to flag suspicious sensor behavior.
  • Containerized deployment with Docker for repeatable environments across development and demo.
  • Role-based access control so admins, operators, and read-only stakeholders see only what they should.

Outcome

The stack mirrors how small teams ship real software: a typed API layer, a modern frontend, PostgreSQL for integrity, and security baked into auth and authorization—not bolted on at the end.
